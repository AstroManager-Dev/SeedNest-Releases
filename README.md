## Über SeedNest

SeedNest ist eine native Android-App für die Organisation privater Cannabis-Samensammlungen. Sorten, Breeder, Mengen, Lagerorte, QR-Etiketten, Bestandsbewegungen, Planungen und lokale Sicherungen lassen sich strukturiert verwalten.

Die aktuelle Alpha kann **ohne SeedNest-Konto** für die lokale Sammlung verwendet werden. Weitere Cloud- und Rollenkonzepte sind noch in Entwicklung.

## Downloads und Updates

Die signierte APK und ihre SHA-256-Prüfsumme liegen bei [GitHub Releases](https://github.com/AstroManager-Dev/SeedNest-Releases/releases). Der [dauerhafte Download-Link](https://astromanager-dev.github.io/SeedNest-Releases/download/) zeigt immer auf die freigegebene Version aus `latest.json` – auch bei Alpha-Prereleases.

**Wichtig:** Vor jedem Update ein Backup **außerhalb der App** erstellen und die APK über der bisherigen Installation installieren. **Nicht vorher deinstallieren.**
