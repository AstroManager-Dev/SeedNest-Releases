SeedNest is a native Android application for managing private cannabis seed collections. Organise strains, breeders, seed counts, storage locations, QR labels, inventory movements, run plans and local backups.

The public alpha supports local collection management **without creating a SeedNest account**. Cloud catalogue, account roles and other planned features are not included in the current APK.

## Downloads

Official signed APKs and SHA-256 files are published at [GitHub Releases](https://github.com/AstroManager-Dev/SeedNest-Releases/releases). Use the [permanent latest APK link](https://astromanager-dev.github.io/SeedNest-Releases/download/) to get the current version from the approved `latest.json` manifest, including prereleases.

**Back up your collection outside the app before updating; install the new APK over your existing installation. Never uninstall as an upgrade shortcut.**

The public website is built from `stats/` and hosted on GitHub Pages. Private analytics require a verified allowlisted GitHub identity through the [admin page](https://astromanager-dev.github.io/SeedNest-Releases/admin/), once OAuth configuration has been completed.
