# Installing SeedNest

**Language / Sprache:** [🇩🇪 Deutsch](INSTALLATION.md) | **🇬🇧 English**

SeedNest requires **Android 8 or newer**.

1. Open the official [Releases page](https://github.com/AstroManager-Dev/SeedNest-Releases/releases) and download the APK for the version you want to install.
2. If you already have a collection, first save a complete backup **outside the app's private storage**.
3. Open the APK. Android may require you to allow installations from the browser or file manager used for the download.
4. **Update SeedNest over the existing installation. Do not uninstall the previous version first.**
5. The first time a version with the update feature starts, read and confirm the introductory notice.

The initial installation, including upgrading from the old Alpha 20 builds to Alpha.0.5.001 or newer, is done manually. Later updates can be offered through the in-app update interface; see [Update instructions (German)](UPDATES.md).

**Important:** Uninstalling may delete your local collection and app data. Updates are designed to preserve data, but verified backups are essential during alpha testing. If Android reports a signature or package error, **do not uninstall as a workaround**. Record your currently installed version and submit a bug report instead.
