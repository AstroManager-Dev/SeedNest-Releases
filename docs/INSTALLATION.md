# Installation

SeedNest benötigt Android 8 oder neuer.

1. Unter [Releases](https://github.com/AstroManager-Dev/SeedNest-Releases/releases) die APK der gewünschten Version herunterladen.
2. Bei vorhandenem Bestand zuerst ein vollständiges Backup außerhalb der App sichern.
3. APK öffnen und gegebenenfalls der verwendeten Download-App das Installieren aus dieser Quelle erlauben.
4. SeedNest über die bestehende Installation aktualisieren. Nicht vorher deinstallieren.
5. Beim ersten Start einer Version mit Updatefunktion den einmaligen Hinweis lesen und bestätigen.

Die Erstinstallation beziehungsweise der Wechsel von Alpha 20 auf eine Version ab Alpha.0.5.001 erfolgt manuell. Danach können zukünftige Versionen direkt in der App angeboten werden. Siehe [Updates](UPDATES.md).

Deinstallation entfernt lokale App-Daten. Ein Update soll Daten erhalten; Backups bleiben bei einer Alpha-Version wichtig. Erscheint eine Signatur- oder Paketfehlermeldung, nicht vorschnell deinstallieren, sondern einen Fehlerbericht mit der bisherigen Version erstellen.
