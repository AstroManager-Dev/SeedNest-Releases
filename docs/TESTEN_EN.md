# SeedNest – Beta Testing Guide

**Language / Sprache:** [🇩🇪 Deutsch](TESTEN.md) | **🇬🇧 English**

Thank you for testing SeedNest! Please begin with a few sample records and make a complete backup elsewhere before using valuable collection data.

- **Create records:** Use the + button to add a strain manually or capture information from a package photo. Review detected facts and **actual on-hand seed quantity** before saving.
- **Invoices – EXPERIMENTAL:** Import a PDF or image; inspect each proposed strain, pack size, price and quantity before accepting the preview. Never rely on unverified OCR results.
- **Storage:** Create a storage bag or location, assign containers, and move containers between places.
- **Collection views:** Test search, favorites, filters, sorting, list layouts and returning from strain profiles. Check that autoflower and photoperiod types stay distinct.
- **Research:** If you wish, configure your own Gemini API key, research a strain, and compare proposals with the stated sources before accepting them.
- **Run planning:** Plan strains and quantities. Starting an active Run can deduct used seeds from inventory; ending it does not restore seeds already used.
- **Container IDs:** Each new container receives a fixed number. Editing and moving it must not change that number.
- **Code 128 jar labels:** Print a new sheet, insert a label into a jar, and scan it. Rotate the phone or jar if needed. Test an older QR label too.
- **PDF/printing:** Preview PDFs and zoom. Only confirm print completion **after every page in that job has actually printed**. Cancelled and incomplete jobs must not be recorded as printed.
- **Updates:** Check **More → Updates & Changelog** and open the offline changelog.
- **On-device AI – EXPERIMENTAL:** Device compatibility, memory use and recognition may vary. Always verify suggestions and use manual entry if the model fails.

## Reporting a bug

Use [GitHub Issues](https://github.com/AstroManager-Dev/SeedNest-Releases/issues/new/choose), or choose **More → Report bug by email** in SeedNest. The optional diagnostic attachment is under your control; the app opens your email application and **does not send a report automatically**.

Include the SeedNest version, phone model, Android version, step-by-step reproduction instructions, expected result and actual result. A screenshot or diagnostics are optional. For OCR problems, the extracted text helps. For research problems, provide the strain name, breeder, auto/photo classification and source URL.

**Privacy:** Never post API keys, private collection backups or unredacted invoices in public reports. Suggestions to improve the user interface are welcome too.
