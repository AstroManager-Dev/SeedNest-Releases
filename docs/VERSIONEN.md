## Vorherige veröffentlichte Alpha (historischer Stand)

### [Alpha.0.5.007 · 9. November 2026](https://github.com/AstroManager-Dev/SeedNest-Releases/releases/tag/Alpha.0.5.007)

Die neuesten öffentlich veröffentlichten Änderungen betreffen **dauerhafte Behälternummern**, **Code-128-Dosenetiketten** und deren QR-Kompatibilität.

- Behälternummern bleiben auch nach Umräumen unverändert und werden nicht erneut automatisch vergeben.
- Dosenetiketten können Code 128 statt QR darstellen; die alten QR-Etiketten bleiben gültig.
- Vor einem Update ein Backup außerhalb der App erstellen. Physische Druck- und Kameratests auf verschiedenen Geräten sind weiterhin offen.

## Was bedeuten die Kanäle?

| Kennzeichnung | Aussage |
|---|---|
| **Alpha / Prerelease** | Testversion; einzelne Funktionen und Datenformate können sich ändern |
| **GitHub Release** | Veröffentlichte APK mit zugehöriger SHA-256-Datei, Notes und Downloadstatistik |
| **latest.json** | Von der Android-App gelesene Versionsmetadaten; wird nur nach einem geprüften Release aktualisiert |
| **Geplant** | Roadmap-Eintrag, **kein** bereits veröffentlichter Funktionsumfang |

Eine ältere APK sollte nicht ohne triftigen Grund über eine neuere Installation installiert werden. Für Updates immer [Installations- und Sicherungshinweise](INSTALLATION.md) beachten.
