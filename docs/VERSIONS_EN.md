## Latest published alpha build

### [Alpha.0.5.007 · 9 November 2026](https://github.com/AstroManager-Dev/SeedNest-Releases/releases/tag/Alpha.0.5.007)

The latest public release focuses on **permanent container numbers**, **Code 128 jar labels** and compatibility with existing QR labels.

- Container numbers stay unchanged when moving a container and are not automatically reused.
- Jar labels can use Code 128 or QR codes; existing QR codes remain valid.
- Always make an external backup before upgrading. Real-device printing and camera tests remain outstanding.

## Release status terminology

| Label | Meaning |
|---|---|
| **Alpha / prerelease** | Testing version; some features and data formats may change |
| **GitHub Release** | Published APK plus checksum, release notes and download metadata |
| **latest.json** | Version metadata read by SeedNest; updated only after a verified release |
| **Planned** | Roadmap item, **not** a feature already shipped in the public APK |

Do not attempt to downgrade without a specific reason. Always follow the [installation and backup guide](INSTALLATION_EN.md).
