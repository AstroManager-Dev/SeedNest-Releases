# SeedNest – Sicherheitsmeldungen / Security Policy

**Deutsch:** SeedNest wird als Alpha getestet. Sicherheitsprobleme in APKs, Updateprüfung, Freigaben, OAuth, Backendzugriff oder Datenhaltung sollten **nicht mit Exploit-Details öffentlich veröffentlicht** werden.

**Kontakt:** [E-Mail an den Projektbetreiber](mailto:m.nause79@gmail.com?subject=SeedNest%20-%20Security%20Report) mit dem Betreff `SeedNest – Security Report`. Bitte betroffene Version, Auswirkung, reproduzierbare Schritte und eine kontaktierbare Rückadresse angeben. Keine vollständigen Nutzerbackups, privaten Schlüssel oder unnötigen personenbezogenen Daten senden.

- Bitte keine fremden Konten oder Daten ohne Berechtigung prüfen.
- Eine private Meldung begründet keine Zusage zu Bearbeitungsfristen oder Prämien.
- Nicht sicherheitskritische Fehler und Funktionswünsche gehören in die [öffentlichen Issue-Vorlagen](https://github.com/AstroManager-Dev/SeedNest-Releases/issues/new/choose).
- **Supportumfang:** veröffentlichte Alpha-Versionen sind Testversionen. Reproduzierbarkeit und Geräteumgebung entscheiden über die Priorisierung.

---

**English:** For vulnerabilities affecting SeedNest alpha releases, APK updates, permissions, OAuth, backend access or local data, please use a **private email report** rather than publishing exploit details.

**Contact:** [Email the maintainer](mailto:m.nause79@gmail.com?subject=SeedNest%20-%20Security%20Report) with subject `SeedNest – Security Report`. Include affected version, impact, reproduction steps and a contact address. Do not send private collection archives, credentials or unnecessary personal data. No response deadline or bounty is promised.
